CharterGuard

A charter is a promise a DAO makes to itself — spending caps, procedure, a ban on self-dealing. CharterGuard holds proposals to that promise: file the proposal with the charter text, and let GenLayer validators compare them article by article and rule on compliance, on-chain, where neither side can rewrite the verdict.

File a proposal — the brief

Paste the proposal text and the charter text exactly as written. Sources are optional: add them only when a compliance question depends on a live fact, such as a treasury balance or a registry entry. Validators rule on the texts first.

CharterGuard rules on compliance; it does not execute proposals and it moves no funds. Rulings judge the filed texts and sources only. Stable Studionet · test network only, no real funds.
